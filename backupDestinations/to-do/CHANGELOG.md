# Backup Destinations changelog

## 1.2.0 - 27/11/2026

- Unlocks OneDrive (Microsoft Graph OAuth) destination UI alongside Google Drive, SFTP/SCP, FTP, S3-compatible, Dropbox, and Incremental.
- Local storage remains a core Destinations feature (path + toggle); this package only unlocks remotes.

## 1.1.0 - 27/11/2026

- Unlocks FTP and Dropbox destination UIs in addition to Google Drive (Disk), SFTP/SCP, S3-compatible, and Incremental.
- Featured in Plugin Store Backup category; keywords expanded for destination search.

## 1.0.0 - 15/10/2026

- Initial Host package: unlocks Google Drive, Remote SFTP/SCP, S3-compatible, and Incremental backup UIs via feature flag `backup-destinations`.
