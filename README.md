# CPN-Plugins

Community plugin catalog for **CPN Panel** (Control Panel Network).

Plugins install under `/home/<domain>/plugins/<plugin-id>/` (subdomains nest under the parent domain home).

This catalog is maintained for CPN. It is not CyberPanel and must not be branded as CyberPanel in the panel UI.

## Catalog

CPN Panel fetches the `main` branch tarball and discovers plugin folders that contain `meta.xml` (and optional `cpn-plugin.json`).
