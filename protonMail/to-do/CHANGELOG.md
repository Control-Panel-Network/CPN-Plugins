# Changelog - protonMail

## [1.0.0] - 08/10/2026

### Added

- Host-scoped Email plugin unlocking CPN **Email → Proton Mail** (`/email/proton`)
- Open Proton Mail (https://mail.proton.me) with optional custom label
- Operator settings fields for account email display, Bridge host/ports, notes
- Honest copy: external Proton / Bridge; CPN does not host Proton encryption
- install-host.sh / uninstall-host.sh feature flag under `/var/lib/cpn/features/proton-mail.enabled`
