# Test Plugin

A simple test plugin to demonstrate the CPN plugin system functionality.

**Version:** 1.0.0  
**Type:** Utility  
**Pricing:** 🟢 **FREE**  
**Author:** master3395

## Description

A basic plugin for testing CPN plugin installation, management, and functionality.

## Features

- Basic plugin structure
- Settings page
- Plugin information API
- Clean URL routing

## Installation

1. Download the plugin ZIP file
2. Upload via CPN Plugin Manager
3. Install and activate

## URLs

- **Main URL:** `/plugins/testPlugin/`
- **Settings URL:** `/plugins/testPlugin/settings/`

## Requirements

- CPN 2.5.5-dev or higher
- Python 3.6+
- Django (as used by CPN)
