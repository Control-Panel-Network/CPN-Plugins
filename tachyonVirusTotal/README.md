# Tachyon VirusTotal

Free Email-category CPN plugin that installs the Tachyon `virustotal` extension.

- Works **without** an API key (GUI links from local SHA-256 / URL)
- Optional free public API key for inline results
- Create account: https://www.virustotal.com/gui/join-us
- Get API key: https://www.virustotal.com/gui/my-apikey
- API docs: https://docs.virustotal.com/docs/api-overview

```bash
sudo bash install-host.sh
```
